The browser blocked the request because the API only accepts calls from its own website (CORS). Open this file in a Chrome window started with web security off, using a throwaway profile: & "$env:ProgramFiles\Google\Chrome\Application\chrome.exe" --disable-web-security --user-data-dir="$env:TEMP\chrome-cors" "file:///$((Resolve-Path .\water_meter.html) -replace '\\','/')" Run it from the folder that holds this file. Close that window when done; don't browse other sites in it.
